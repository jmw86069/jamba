# Match unique vector values against itself

Match unique vector values against the full vector

## Usage

``` r
match_unique(x, ...)
```

## Arguments

- x:

  `vector`

- ...:

  additional arguments are ignored

## Details

This function matches unique vector values to the full vector. This step
may be commonly performed to subset another R object for example.
